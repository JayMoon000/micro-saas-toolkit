## 5. 추가 추천 유틸리티 툴 리스트 (Backlog)

### 📊 1. 생활 및 금융 계산기 (Financial & Daily Calc)
* **퍼센트 계산기 (Percentage Calculator)**
  * 전체값의 X% 계산, 값의 증가/감소율(%) 계산, 비율 환산.
  * *특징:* 글로벌 연간 검색량 최상위, 순수 JS 공식 3~4줄로 초간단 구현.
* **복리 계산기 (Compound Interest Calculator)**
  * 원금, 이자율, 기간, 납입 주기에 따른 최종 자산 시뮬레이션 및 연도별 간단 표 출력.
  * *특징:* 금융/투자 키워드 매칭으로 애드센스 고단가(High CPC) 유도 가능.
* **할인율 & 세일 계산기 (Discount & Sale Price Calculator)**
  * 정가와 할인율(%) 입력 시 최종 결제 금액 및 절약 금액 계산.

### 🔄 2. 글로벌 단위 및 환산 도구 (Unit Converters)
* **온도 변환기 (Temperature Converter: °C ↔ °F)**
  * 섭씨(Celsius)와 화씨(Fahrenheit) 실시간 양방향 변환.
  * *특징:* 미국 등 영미권 사용자의 생활 필수 검색 키워드.
* **길이/무게 변환기 (Length & Weight Converter)**
  * 인치(in) ↔ 센티미터(cm), 피트(ft) ↔ 미터(m), 파운드(lbs) ↔ 킬로그램(kg).
* **디지털 데이터 용량 계산기 (Data Size Converter)**
  * B, KB, MB, GB, TB 간 단위 환산.

### ✍️ 3. 텍스트 및 개발 편의 도구 (Text & Dev Utilities)
* **글자 수 / 단어 수 세기 (Character & Word Counter)**
  * 공백 포함/제외 글자 수, 영문 단어 수(Word Count), 읽기 예상 시간(Reading Time) 실시간 표시.
* **영문 대소문자 변환기 (Case Converter)**
  * UPPERCASE, lowercase, Title Case, camelCase, kebab-case 원클릭 변환 및 복사.
* **Unix 타임스탬프 변환기 (Epoch & Unix Timestamp Converter)**
  * 날짜(YYYY-MM-DD) ↔ 타임스탬프(초/밀리초) 상호 변환.
  
  
  
  깔끔한 4개 카테고리 구성 (4개씩 4그룹):

Text & Code (4개): Base64, URL 인코더, JSON 포매터, Case 변환기

Web & Design (4개): WebP/이미지 압축, CSS Box-Shadow/Gradient, Color/HEX 변환기, SVG to DataURI

Dev & Security (4개): Hash(SHA-256) 생성기, UUID 생성기, Epoch 타임스탬프, Regex 테스터

Daily Utility (4개): 글자수 세기, QR코드 생성기, 마크다운 미리보기, 텍스트 Diff(비교)
