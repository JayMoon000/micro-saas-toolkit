📊 '그래프 / 시각화' 연장통 후보 아이디어

1. 텍스트 $\rightarrow$ 1초 다이어그램 / 마인드맵 변환기 (Mermaid.js 활용)
 - 불편함: 보고서나 기획서 쓸 때 순서도(Flowchart)나 조직도, 마인드맵을 그리려면 피그마나 PPT 켜서 네모 박스 그리고 화살표 연결하느라 시간을 다 씀.
 - 솔루션: 텍스트로 [시작] -> [결제] -> [완료] 이렇게 간단하게 적거나 줄바꿈으로 목록만 적으면, 브라우저가 알아서 깔끔하고 예쁜 다이어그램 이미지(PNG/SVG)로 바로 뽑아주는 툴! (다운로드받아서 바로 PPT에 붙여넣기용)
 
2. 엑셀 없이 그리는 '10초 초간단 차트 생성기'
 - 불편함: 블로그 글 쓰거나 커뮤니티에 데이터 올릴 때, 엑셀 켜서 데이터 입력하고 차트 만들어서 캡처하는 과정이 은근히 번거로움.
 - 솔루션: 숫자가 적힌 텍스트나 표를 복사-붙여넣기 하면 바로 감성적인 파이 차트, 막대그래프, 선 그래프로 변환되고 이미지 파일로 저장할 수 있는 미니 차트 도구.
 
3. 주식/재테크 유저용 '목표 수익률 / 복리 비주얼 계산기'
- 불편함: 단순히 숫자로 "10년 뒤 얼마 됩니다" 보여주는 계산기는 많은데, 내 자산이 연도별로 어떻게 불어나는지 한눈에 직관적인 스택 그래프로 보여주는 깔끔한 툴은 잘 없음.
- 솔루션: 원금, 월 적립액, 예상 수익률만 넣으면 깔끔한 자산 성장 곡선 그래프를 그려주고 이미지 저장까지 되는 툴.

4. 네트워크 / 관계도 시각화 툴
- 불편함: 인물 관계도, 소설/드라마 등장인물 구도, 혹은 업무 프로세스 간의 연결 고리를 시각적으로 만들고 싶은데 전용 프로그램은 너무 복잡함.
- 솔루션: "A -> B (친구)", "B -> C (적대)" 이렇게 텍스트만 치면 동그라미 선으로 연결된 예쁜 관계도 그래프를 자동으로 그려주는 툴.
